# Emby Migrator v1.1.5

`v1.1.5` 加强导出完整性、增量导出一致性、迁移包路径安全和媒体数据库目标校验。

## 导出与增量

- 媒体图片下载或写入失败会记录到导出包 `manifest.json`，保留已成功导出的内容，同时将任务标记为未完全成功。
- 人物头像临时请求失败会纳入导出错误统计；人物确实没有头像时继续正常跳过。
- 导出包记录图片类型、人物头像和媒体技术信息等选项。只有选项一致时才复用增量基线，避免新增导出内容被错误跳过。
- 旧版本导出包没有选项快照时不会直接作为增量基线，首次按全量导出处理。

## 安全与可靠性

- 导入读取迁移包文件时解析符号链接并再次校验目录边界，阻止包内链接读取挂载目录中的包外文件。
- Emby 查询发生临时错误时不再缓存失败结果，后续重试会重新请求服务器；成功结果仍然复用缓存。

## 媒体数据库

- 媒体数据库计划升级为 schema 2，绑定目标 ServerID、数据库 schema 身份以及全部目标项目的 ID/名称摘要。
- 自动停启模式会在停止 Emby 容器前在线读取 `/System/Info`，严格校验目标 ServerID 和版本系列。
- 在线身份、版本、数据库 schema 或项目锚点不匹配时，在停止容器、创建备份和写入数据库前终止任务。
- 继续支持 Emby `4.8.11.x -> 4.8.11.x` 和 `4.9.5.x -> 4.9.5.x` 的同系列媒体技术信息恢复。
- 手动停服模式保留数据库 schema 和项目锚点校验；由于 `library.db` 不保存可靠 ServerID，页面日志会明确提示该模式无法独立验证数据库所属实例。
