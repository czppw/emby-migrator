# Emby Migrator v1.1.4

`v1.1.4` 集中修复代码审查发现的认证安全、导入性能、任务可靠性和发布流程问题。

## 安全

- 新密码改用 bcrypt 保存；现有 `sha256:v1` 密码在成功登录后自动迁移，无需重置账号。
- 修改账号或密码后递增会话版本，使其他设备上的旧会话立即失效。
- 登录按客户端 IP 和账号限流，连续失败 5 次后锁定 5 分钟。
- 随机数生成失败时不再使用时间戳回退。
- 支持反向代理的 HTTPS Secure Cookie，并增加安全响应头、JSON 请求体上限和 HTTP 超时。
- 内部错误和 panic 不再直接返回具体服务器信息。

## 性能与可靠性

- 导入 checkpoint 改为内存缓存和 JSONL 追加日志，结束时原子压缩，消除逐项全量读写造成的 O(n²) 写放大。
- checkpoint 支持项目和人物头像的异常中断恢复，完成、失败和取消都会执行最终落盘。
- 导出先写入 `.partial` 临时目录，成功后原子发布；失败或取消自动清理。
- 默认单任务最大并发为 64，可通过 `EMBY_MIGRATOR_MAX_CONCURRENCY` 调整，设为 `0` 可关闭限制。
- Emby 数据库备份只保留同一数据库最近 5 份项目备份，不影响手动备份。

## 兼容与工程质量

- 修复包含 `/`、`?`、`#`、空格或非 ASCII 字符的人物姓名 URL 转义。
- 修复稳定键整数转换不支持负数的问题。
- SQLite、Go 加密库和构建工具链升级；发布镜像使用 Go 1.26.5 构建。
- GitHub Actions 新增格式、全量测试、`go vet` 和构建门禁，Docker 发布必须等待 CI 成功。
- 页面版本由后端统一提供，README 版本徽章自动读取最新 GitHub Release。

## 验证

- Go 1.26.5 下全量测试、`go vet` 和服务器构建通过。
- 认证、checkpoint 和数据库备份重点测试连续执行 10 次通过。
- GitHub Actions workflow 通过 `actionlint`。
- `govulncheck` 调用链漏洞为 0。
